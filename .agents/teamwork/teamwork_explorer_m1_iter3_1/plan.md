# Implementation Plan — Fix Partial Streaming Download Truncation

## Target File
`parasite_ai/mind/brain_manager.py` (lines 759–800)

## Problem Summary
When an HTTP streaming response cleanly terminates prematurely without throwing an exception (e.g. truncated connection or socket cutoff), `_download_worker` exits the stream loop and proceeds to atomically rename `temp_path` to `target_path`.
If the partial stub contains >= 8 bytes with magic `b"GGUF"` and version 2 or 3 (as in the 128-byte test stub generated by `TruncatedCleanCloseStream`), `validate_gguf_header(target_path)` passes, incorrectly promoting the truncated file to `BrainState.MODEL_READY_ON_DISK` with `progress.status = 'completed'` and `100.0%`.

## Core Solution Architecture
1. **Size Completeness Check Before Promotion**:
   Inspect `bytes_downloaded` and `temp_path.stat().st_size` against `real_total`.
   If `(real_total > 0 and bytes_downloaded < real_total) or (real_total > 0 and temp_size < real_total) or temp_size == 0`:
   - Log an error with actual vs expected bytes.
   - Delete/unlink `temp_path`.
   - Update `self.state = BrainState.DOWNLOAD_FAILED` and `self._current_progress.status = "failed"` under `self._lock`.
   - Notify `progress_callback` (outside the lock).
   - Return immediately without touching `target_path`.

2. **Pre-Promotion Staging Validation**:
   Validate the GGUF header on `temp_path` **before** renaming to `target_path`.
   If invalid:
   - Unlink `temp_path`.
   - Transition to `BrainState.DOWNLOAD_FAILED` and `status = "failed"`.
   - Return without overwriting `target_path`.

3. **Atomic Destination Replacement**:
   Only promote `temp_path` to `target_path` if both size completeness and header validation succeed.

## Contract Alignment Note
- **State Enum**: Use `BrainState.DOWNLOAD_FAILED`. The dispatch prompt mentioned `BrainState.ERROR_DOWNLOAD_FAILED` colloquially, but in the codebase `BrainState` only defines `DOWNLOAD_FAILED`. Using `ERROR_DOWNLOAD_FAILED` will raise `AttributeError` and fail `test_challenger_m1_iter2_1.py:519` (`assert manager.state == BrainState.DOWNLOAD_FAILED`).
- **Progress Status**: Use `status = "failed"`. The `DownloadProgress` model defines `status: str` with allowed values `downloading, verifying, completed, failed, cancelled`. Tests in `test_brain_manager.py:426`, `test_stress_gguf.py:261`, and `test_challenger_m1_iter2_1.py:481` assert `events[-1].status == "failed"`.

                    # Completeness Verification: Detect truncated / premature stream termination
                    temp_size = temp_path.stat().st_size if temp_path.exists() else 0
                    if (real_total > 0 and bytes_downloaded < real_total) or (real_total > 0 and temp_size < real_total) or temp_size == 0:
                        logger.error(
                            "Download incomplete for %s: received %d of %d expected bytes (on-disk: %d bytes)",
                            filename,
                            bytes_downloaded,
                            real_total,
                            temp_size,
                        )
                        if temp_path.exists():
                            try:
                                temp_path.unlink()
                            except Exception:
                                pass
                        with self._lock:
                            self.state = BrainState.DOWNLOAD_FAILED
                            if self._current_progress:
                                self._current_progress.status = "failed"
                        if progress_callback and self._current_progress:
                            progress_callback(self._current_progress)
                        return

                    # Download finished - Validate GGUF header
                    with self._lock:
                        if self._current_progress:
                            self._current_progress.status = "verifying"
                        if progress_callback and self._current_progress:
                            progress_callback(self._current_progress)

                    # Validate staging temporary file before replacing destination
                    is_valid = validate_gguf_header(temp_path)
                    if not is_valid:
                        logger.error("Downloaded file %s failed binary GGUF header validation", filename)
                        if temp_path.exists():
                            try:
                                temp_path.unlink()
                            except Exception:
                                pass
                        with self._lock:
                            self.state = BrainState.DOWNLOAD_FAILED
                            if self._current_progress:
                                self._current_progress.status = "failed"
                        if progress_callback and self._current_progress:
                            progress_callback(self._current_progress)
                        return

                    # Atomically promote verified temporary file to destination
                    if temp_path.exists():
                        if target_path.exists():
                            try:
                                target_path.unlink()
                            except Exception:
                                pass
                        temp_path.replace(target_path)

                    with self._lock:
                        self.state = BrainState.MODEL_READY_ON_DISK
                        self.current_model = filename
                        if self._current_progress:
                            self._current_progress.status = "completed"
                            self._current_progress.percentage = 100.0

                    if progress_callback and self._current_progress:
                        progress_callback(self._current_progress)
