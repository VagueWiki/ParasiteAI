## 2. Proposed Changes & Technical Architecture

### 2.1 Circular Import Elimination in `parasite_ai/vision/capture.py`
* **Problem:** Top-level `from parasite_ai.safety.window_guard import ensure_interactive_desktop` pulls `parasite_ai.safety.__init__` -> `risk_gate` -> `memory` -> `dual_mind` -> `foveated` -> `capture.py`, causing `ImportError: cannot import name 'ScreenCapture' from partially initialized module 'parasite_ai.vision.capture'` when `test_grounding.py` is imported directly.
* **Solution:** Replace top-level import in `capture.py` with:
  ```python
  def _safe_ensure_interactive_desktop() -> bool:
      """Lazily invokes ensure_interactive_desktop without circular package imports."""
      try:
          from parasite_ai.safety.window_guard import ensure_interactive_desktop
          return ensure_interactive_desktop()
      except Exception:
          return False
  ```
  Invoke `_safe_ensure_interactive_desktop()` in `ScreenCapture._init_backend()`, `_get_thread_sct()`, and `capture_screen()`.

### 2.2 Two-Tier Shallow UIA Drill-Down in `ScreenGrounder` (`parasite_ai/vision/grounding.py`)
* **Configuration:** Add `shallow_drill_down: bool = True` in `VisionConfig` (`parasite_ai/config.py`).
* **`ax_overview(window_filter: Optional[int] = None, max_depth: int = 3) -> List[RawElement]`:**
  - Traverses the root control up to `max_depth` (default 3), extracting container boundaries (e.g. `PaneControl`, `ToolBarControl`, `ListControl`, `TreeControl`, `DialogControl`, `TabControl`).
  - Returns container boundaries with their `control_ref`, bounding rectangles, and labels in `<15ms`.
* **`ax_subtree(container: Any, max_depth: int = 5, goal_keywords: Optional[List[str]] = None) -> List[RawElement]`:**
  - Performs a targeted walk starting from the specified container node down to `max_depth` (default 5).
  - Skips navigation trees, status bars, and other unrelated subtrees when focusing on list views or dialog panes.
* **Integration into `ground()`:**
  - When `self.config.shallow_drill_down` is `True` and the active window has container controls:
    - Runs `ax_overview()` to discover target panes.
    - Selects relevant containers (focused pane, matching goal keywords, or main content list) and calls `ax_subtree()`.
    - If shallow drill-down returns fewer elements than `_min_uia_threshold` or if `shallow_drill_down` is disabled, seamlessly falls back to full `_walk_uia_tree_inner()`.
    - Resolves in `<50ms` while retaining exact physical coordinates for Bézier mouse curves.
