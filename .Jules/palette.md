## 2024-11-06 - Tooltips for Context
**Learning:** Adding informative tooltips to interactive elements clarifies their functions, especially for more complex AI tools like "Panic Abort" or specific model selection drop downs.
**Action:** When working on complex desktop application UI interfaces with PyQt, consistently consider adding `setToolTip` explanations to inputs, checkboxes and key action buttons to improve user understanding without cluttering the screen with text.
