# ParasiteAI Universal Skill Library (`data/skills/`)

Playbooks in this directory are stored as human-readable and agent-editable `SKILL.md` files (YAML frontmatter + Markdown instructions).

## Directory Conventions

- `<skill_id>/SKILL.md` — Active or candidate playbooks loaded by `SkillRegistry.load_all()`.
- `_template/SKILL.md` — Reference template (directories prefixed with `_` are never loaded as active skills).
- `_traces/` — Deterministic raw local execution traces captured by `TraceRecorder` (never uploaded off-box).
- `_quarantine/` — Invalidated, visually drifted, or rejected skills moved here by `SkillRegistry.quarantine()` (never deleted).

## Two Strict Skill Types

1. **`type: workflow` (default):**
   - Strictly semantic (`LivingPlan` compilation). Must contain **zero** pixel coordinates anywhere in YAML or Markdown body.
   - Local `UI-TARS-1.5-7B` grounds visual targets in native desktop pixels at execution time.

2. **`type: reflex_micro_skill` (§7.6 Gated Exemption):**
   - Reserved for fixed-layout micro-skills (e.g., keypads, static compound click bursts).
   - Permits `relative_coordinates: [rx, ry]` ONLY when paired with `reflex_gate` specifying `expected_window_size`, `relative_origin`, and a 64-bit `phash_anchor`.
   - At runtime, `verify_and_resolve_reflex_skill()` enforces all 4 §7.6 gates (client-relative domain, exact OS window dimensions, sub-5 ms pHash check, fail-closed abort to UIA/VLM on any mismatch).

## Lifecycle & Discord Approval Gate

- Co-authored skills generated by `SkillLearner` are always saved with `draft: true` and `state: CANDIDATE`.
- Draft skills are excluded from matching until the operator clicks **[Approve & Enable]** in Discord (`SkillApprovalView`) or sets `draft: false` manually.
- Visual anchors use 64-bit DCT perceptual hashes (`compute_phash`) captured from OS-verified container window rectangles. Skills exceeding `phash_max_hamming`, exceeding `max_consecutive_failures`, or failing approval move to `_quarantine/`. Skills unverified past `ttl_days` (default `30`) decay to `STALE`.
